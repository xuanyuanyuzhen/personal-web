## 1. 项目概述

语尔是一个偏粉色、安静记录风格、带二次元元素的个人记录站。

项目由三部分组成：

- 前台个人网站：公开访问，用于展示公开内容。
- 后台管理系统：管理员登录后维护内容和站点配置。
- 后端接口服务：提供内容管理、登录鉴权、上传、统计、审核、搜索等能力。

网站不以技术履历展示为主，核心是记录个人经验、碎碎念、随笔、照片墙、留言互动和个人兴趣氛围。

## 2. 产品目标

第一版目标：

- 搭建完整前后端闭环，而不是只做静态页面或 mock UI。
- 前台具备完整个人站访问体验。
- 后台具备内容维护、审核、配置和基础统计能力。
- 后端使用 MySQL 持久化数据。
- 支持后续扩展自定义页面、Live2D、对象存储、验证码、限流、备份等能力。

非目标：

- 第一版不强调技术作品集。
- 第一版不做访客登录系统。
- 第一版不做 RSS。
- 第一版不做 Sitemap。
- 第一版不做 Docker 化运行。
- 第一版不做数据备份导出界面。

## 3. 用户角色

### 3.1 访客

- 不需要登录即可访问前台。
- 只能查看已发布且公开的内容。
- 可以查看碎碎念、随笔、照片墙、留言板、关于我、自定义页面等公开内容。
- 可以留言。
- 可以点赞。
- 可以使用前台搜索。

### 3.2 管理员

- 当前只支持一个管理员账号。
- 管理员需要登录后台。
- 管理员可以管理内容、导航、自定义页面、照片、留言、评论、标签、音乐、看板娘、系统设置等。
- 管理员可以从后台进入前台预览模式。
- 管理员预览模式下，可以查看仅自己可见内容。

## 5. 前台需求

### 5.1 整体视觉

- 整体以粉色系为主。
- 氛围偏安静记录。
- 首页第一眼像日记本。
- 首页需要二次元角色介绍和网站介绍。
- 前台所有内容列表尽量多样化排版。
- 多样化排版需要保持统一视觉风格，但卡片布局、尺寸、节奏可以变化，避免模板化重复。
- 前台需要适配桌面端和移动端。

### 5.2 主题与动画

- 前台需要夜间模式。
- 夜间模式不能直接使用纯黑。
- 夜间模式使用柔和暗色系，例如低饱和粉紫、灰紫、深樱色。
- 夜间模式切换需要过渡动画。
- 主题选择需要记住用户上次选择。
- 前台需要页面切换动画。
- 页面切换动画应轻柔克制，例如淡入、轻微位移，不影响阅读。
- 前台需要加载动画。
- 加载动画需要符合粉色日记本和二次元氛围。

### 5.3 首页

首页展示：

- 网站名：语尔。
- 公开昵称：轩辕宇振。
- 网站介绍。
- 看板娘占位图。
- 看板娘欢迎语或页面说明。
- 网站公告。
- 最近碎碎念。
- 最近照片。
- 留言板入口。
- 点赞入口。

网站公告：

- 第一版需要公告。
- 公告只在首页显示。
- 公告内容使用富文本编辑。
- 公告由后台维护。
- 首页顶部需要有公告小图标。
- 点击公告小图标可再次显示公告。
- 公告关闭后需要记住关闭状态。

### 5.4 碎碎念

- 支持短句碎碎念。
- 内容可公开展示。
- 内容使用富文本编辑器编辑。
- 支持标签。
- 标签由后台统一维护。
- 前台支持按标签筛选。
- 支持配图。
- 配图通过后台上传和维护。
- 前台列表使用无限滚动。
- 后台管理列表使用分页。
- 心情字段第一版只预留，不在前后台开放。

### 5.5 随笔

- 第一版需要随笔模块。
- 前台导航名称为“随笔”。
- 前台需要随笔列表。
- 前台需要随笔详情页。
- 后台需要随笔管理能力。
- 内容使用富文本编辑器维护。
- 支持公开和仅自己可见。
- 支持草稿和已发布。
- 支持置顶。
- 支持分类。
- 分类后台可维护。
- 前台支持按分类筛选。
- 支持标签。
- 标签使用统一标签管理。
- 前台列表使用无限滚动。
- 后台管理列表使用分页。
- 前台随笔展示排版需要多样化。

### 5.6 照片墙

- 照片由管理员上传。
- 照片墙不以真实生活照片为主。
- 照片可公开展示。
- 每张照片支持标题。
- 每张照片支持描述。
- 前台列表优先展示缩略图。
- 点击照片进入大图预览。
- 大图预览需要有从缩略图逐渐放大并加载高清图的效果。
- 支持相册分类。
- 相册后台可维护。
- 前台支持按相册筛选。
- 支持手动排序。
- 后台支持拖拽排序和手动排序值。
- 照片标签第一版只预留，不开放使用。

### 5.7 留言板

- 前台需要留言板。
- 留言不允许匿名。
- 留言字段：昵称、邮箱、内容。
- 不需要网站链接字段。
- 留言使用默认头像。
- 不支持访客上传头像。
- 不接入 Gravatar。
- 前台留言列表使用无限滚动。
- 后台留言列表使用分页。
- 留言需要违禁词检测。
- 未命中违禁词时自动公开。
- 命中违禁词时进入后台审核。
- 留言回复功能留到后续实现。
- 第一版不做前台回复展示。
- 第一版不做后台回复界面。
- 第一版不实现实际留言回复流程，仅保留扩展位置。

### 5.8 点赞

点赞对象：

- 整个网站。
- 碎碎念。
- 随笔。
- 照片。

规则：

- 支持点赞。
- 支持取消点赞。
- 同一浏览器对同一对象再次点击时取消点赞。
- 使用 localStorage 生成访客 ID。
- 后端基于访客 ID 和点赞对象判断是否已点赞。
- 后台需要按对象类型统计点赞数。
- 点赞交互使用爱心风格。
- 点赞需要动画效果。
- 动画细节后续根据前台模板再细化。

### 5.9 评论接口

- 随笔评论第一版前台暂不展示。
- 后端需要实现评论接口。
- 后台需要支持评论管理。
- 评论复用留言板逻辑。
- 评论走违禁词检测、审核、公开规则。
- 评论额外绑定随笔 ID。
- 评论第一版支持层级回复。
- 评论第一版需要完整 CRUD。
- 后台支持查看、审核、回复、删除评论。

### 5.10 搜索

前台搜索范围：

- 碎碎念。
- 自定义页面。
- 随笔。
- 照片标题和描述。
- 留言内容。

交互：

- 搜索结果按内容分区独立展示。
- 前台需要弹窗快速搜索面板。
- 前台需要独立搜索结果页。
- 弹窗搜索用于快速查看结果。
- 完整搜索结果页用于展示更多分区结果。
- 普通访客只搜索已发布且公开的内容。
- 管理员前台预览模式可搜索管理员可见内容。

后台：

- 后台也需要搜索。
- 后台搜索用于各管理模块内查询内容。

### 5.11 音乐播放器

- 前台需要音乐播放器。
- 播放器在全站固定角落显示。
- 需要避免遮挡内容，尤其是移动端。
- 后台维护音乐列表。
- 支持后台上传本地音乐文件。
- 支持填写外部音乐链接。
- 默认不自动播放。
- 需要记住用户上次播放选择。
- 支持播放列表。
- 支持切换歌曲。
- 支持单曲循环。
- 支持随机播放。
- 支持歌词。
- 有歌词数据时显示歌词。
- 无歌词数据时显示歌曲名和歌手。
- 歌词支持后台手动填写文本。
- 歌词支持上传 `.lrc` 文件。

### 5.12 看板娘

- 第一版使用静态占位图。
- 后续可替换为已有图片。
- 默认全站显示。
- 显示范围后台可配置。
- 需要台词气泡。
- 台词气泡按页面配置。
- 访客进入不同页面时，看板娘展示对应页面说明。
- 点击看板娘后随机显示台词。
- 随机台词池后台维护。
- 每条随机台词配置权重或占比。
- 随机展示时按权重决定概率。
- Live2D 第一版只预留。
- Live2D 作为后续学习和扩展计划。

### 5.13 关于我

- 不强调技术介绍。
- 内容偏个人介绍、兴趣、建站说明。
- 内容使用富文本编辑器维护。
- 展示头像。
- 头像后台上传和维护。
- 展示社交链接。
- 第一版社交链接仅支持 GitHub。
- 不展示联系方式。

### 5.14 错误页

- 第一版需要前台错误页。
- 后台第一版不需要单独设计错误页。
- 前台错误页覆盖 404。
- 前台错误页覆盖 500。
- 错误页可参考 `donlon/cloudflare-error-page`。
- 参考地址：https://github.com/donlon/cloudflare-error-page
- 参考项目许可证为 MIT。
- 错误页不要带有语尔个人站色彩。
- 错误页视觉采用 Cloudflare 风格。
- 错误页提供返回上一页入口。
- 错误页提供重新加载入口。
- 错误页不提供返回首页入口。
- 错误页不提供搜索入口。
- 实现前需要再次确认 Cloudflare 名称、商标和仿官方错误页的使用边界。

## 6. 后台需求

后台第一版要求：

- 只适配电脑端。
- 不要求移动端管理体验。
- 不需要夜间模式。
- 保持浅色管理界面。
- 使用 Element Plus。
- 从零搭建，不使用现成后台模板。

### 6.1 登录与账号

- 后台需要登录。
- 第一版只支持一个管理员账号。
- 登录方式：账号密码。
- 第一版不接入图形验证码或邮箱验证码。
- 登录鉴权使用 JWT + HttpOnly Cookie。
- 登录成功后后端写入 HttpOnly Cookie。
- 后台管理接口通过 JWT 校验管理员身份。
- 登录有效期默认 24 小时。
- 登录页提供“记住我”选项。
- 勾选“记住我”后有效期为 7 天。
- 后台支持修改密码。
- 登录页需要显示默认密码提示。
- 默认账号：`admin`。
- 默认初始密码：`admin123`。
- 生产环境首次使用后需要修改默认密码。

### 6.2 仪表盘

- 第一版需要仪表盘。
- 需要展示统计数据和常用入口。
- 使用 ECharts 做图形化展示。
- 后台表格优先使用 Element Plus 表格。

仪表盘指标：

- 总访问量。
- 今日访问量。
- 最近 7 天访问趋势。
- 最近 30 天访问趋势。
- 点赞总数。
- 最近 7 天点赞趋势。

不放在仪表盘：

- 碎碎念数量。
- 照片数量。
- 留言数量。
- 待审核留言数量。
- 最新留言列表。
- 最新发布内容列表。

这些数量放到各自导航或菜单区域展示。

### 6.3 内容管理通用规则

- 内容统一使用富文本编辑器。
- 富文本编辑器使用 WangEditor。
- 内容支持公开和仅自己可见。
- 内容支持草稿和已发布。
- 内容支持置顶。
- 删除内容进入回收站。
- 定时发布第一版只预留，不开放界面和自动发布流程。

### 6.4 导航与页面管理

- 后台可管理导航。
- 后台可管理自定义页面。
- 导航支持站内页面和外链。
- 导航支持多级菜单。
- 导航支持排序。
- 导航支持父子级关系。
- 自定义页面内容使用 WangEditor。
- 自定义页面 SEO 第一版只预留。

### 6.5 碎碎念管理

- 新增、编辑、删除碎碎念。
- 设置公开或仅自己可见。
- 设置草稿或已发布。
- 设置标签。
- 上传配图。
- 支持置顶。
- 管理列表分页。

### 6.6 随笔管理

- 新增、编辑、删除随笔。
- 设置公开或仅自己可见。
- 设置草稿或已发布。
- 设置分类。
- 设置标签。
- 设置置顶。
- 管理列表分页。
- 评论接口实现，前台暂不展示评论。

### 6.7 照片与相册管理

- 管理员可上传照片。
- 支持批量上传。
- 支持标题和描述。
- 支持相册分类。
- 支持公开和仅自己可见。
- 支持拖拽排序。
- 支持手动排序值。
- 上传后保留原图。
- 上传后生成压缩大图。
- 上传后生成缩略图。

### 6.8 留言审核

- 命中违禁词的留言进入后台审核。
- 管理员决定是否公开。
- 审核状态：待审核、已通过、已拒绝。
- 被拒绝留言保留记录。
- 命中黑名单的留言或评论进入待审核。
- 命中黑名单后不直接拒绝，也不静默丢弃。

黑名单支持：

- 昵称。
- 邮箱。
- IP。
- 浏览器访客 ID。

### 6.9 评论管理

- 评论复用留言审核规则。
- 评论支持完整 CRUD。
- 评论支持层级回复。
- 后台支持查看、审核、回复、删除评论。
- 前台第一版不展示评论。

### 6.10 违禁词管理

- 违禁词词库后台可维护。
- 管理员可新增、编辑、删除违禁词。
- 第一版使用直接命中规则。
- 正则规则能力第一版只预留。
- 第一版不做风险等级。
- 留言或评论命中违禁词后统一进入待审核。
- 需要记录命中的违禁词。
- 后台审核留言或评论时展示命中的违禁词列表。
- 违禁词规则设计可参考腾讯云、阿里云等内容安全产品的字段和分类思路。
- 具体参考模板实现前需要查阅官方资料确认。

### 6.11 标签管理

- 第一版需要统一标签管理。
- 标签由后台统一维护。
- 标签可以设置适用范围。
- 适用范围可覆盖碎碎念、随笔、照片等内容类型。
- 相册分类单独管理，不与标签混用。

### 6.12 音乐管理

- 后台维护音乐列表。
- 支持上传本地音乐文件。
- 支持填写外部音乐链接。
- 支持歌曲名称。
- 支持歌手。
- 支持播放列表。
- 支持歌词文本。
- 支持上传 `.lrc` 文件。

### 6.13 看板娘管理

- 管理看板娘图片。
- 第一版默认使用占位图。
- 配置看板娘显示范围。
- 配置页面台词。
- 配置随机台词池。
- 每条随机台词可配置权重。
- Live2D 配置第一版只预留。

### 6.14 系统设置

系统设置维护：

- 网站名。
- 公开昵称。
- 首页介绍。
- GitHub 链接。
- 默认看板娘配置。
- 网站公告。

主题：

- 第一版前台固定粉色主题。

- 主题色配置能力只预留。

favicon：

- favicon 设置第一版只预留。

公告：

- 第一版需要网站公告。
- 公告后台可编辑。
- 公告使用富文本。

### 6.15 回收站

- 第一版需要回收站。
- 删除默认进入回收站，不直接物理删除。
- 回收站内容可恢复。
- 回收站内容可彻底删除。
- 彻底删除需要二次确认。
- 自动清理能力第一版只预留，不启用。

回收站覆盖：

- 碎碎念。
- 随笔。
- 照片。

- 第一版需要访问统计。

- 不接入第三方统计服务。
- 需要按页面统计浏览量。
- 需要按日期统计访问量。
- 覆盖内置页面和自定义页面。
- 日期维度用于今日访问量、最近 7 天趋势、最近 30 天趋势。
- 不记录访问来源 referrer。
- 可记录访客 IP、浏览器、设备等信息，但需要脱敏。
- IP 不保存完整原始值。
- 浏览器和设备信息只记录大类或必要字段。

### 6.17 操作日志

- 第一版需要后台操作日志。
- 记录管理员登录。
- 记录新增、编辑、删除内容。
- 记录审核留言。
- 记录修改系统设置。
- 记录修改密码。
- 记录管理员操作 IP。
- 管理员操作 IP 完整记录，不脱敏。
- 访客访问统计仍按脱敏规则处理。
- 操作日志保留时间后台可配置。
- 默认保留 90 天。
- 后台界面不允许管理员手动删除操作日志。
- 操作日志按配置保留时间自动清理。
- 如有特殊需要，站长可自行在数据库层面清理。

### 6.18 数据备份

- 数据备份能力第一版只预留。
- 第一版不做数据导出、数据备份界面和备份恢复流程。

## 7. 权限与可见性

内容状态分两个维度：

- 发布状态：草稿、已发布。
- 可见范围：公开、仅自己可见。

规则：

- 普通访客只能看到已发布且公开的内容。
- 管理员后台可以看到全部内容。
- 管理员可从后台进入前台预览模式。
- 管理员预览模式可看到仅自己可见内容。
- 私密内容与仅自己可见视为同一种可见范围。
- 前台搜索遵守同样权限规则。

## 16. 风险与注意事项

### 16.1 Cloudflare 风格错误页

默认账号和密码仅用于初始化和本地开发。

- IP 脱敏。
- 浏览器和设备只记录大类。

管理员操作日志：
