# 语尔个人网站概要设计文档

版本：v1.0  
来源：基于 `doc/prd.md`  
输出目标：将 PRD 中已划分的业务模块转化为可开发、可测试、可扩展的概要设计。

## 1. 设计目标

第一版以“完整前后端闭环”为核心目标，包含前台个人网站、后台管理系统和后端接口服务。设计需要满足：

- 前台公开访问，仅展示已发布且公开的内容。
- 后台由单管理员登录后维护内容、配置、审核、统计和日志。
- 后端提供统一 REST API、Swagger 文档、MySQL 持久化、上传处理、鉴权、搜索、审核、统计等能力。
- 各业务模块尽量保持独立，模块之间通过明确的数据模型、DTO、服务接口和事件边界协作。
- 第一版只实现 PRD 明确列入范围的功能；PRD 标明“预留”“后续实现”“实现前需确认”的功能不在第一版中直接展开为可用流程。

## 2. 总体架构

项目采用 pnpm workspace monorepo：

```text
yuer/
  apps/
    web/      # 前台 Vue 3 + TypeScript + Vite
    admin/    # 后台 Vue 3 + TypeScript + Vite + Element Plus
    api/      # 后端 NestJS + Prisma + MySQL + Swagger
  doc/
    prd.md
    detailed-design.md
```

三端职责：

- `apps/web`：负责前台展示、访客交互、主题、多语言、搜索入口、点赞、留言、音乐播放器和看板娘展示。
- `apps/admin`：负责管理员登录后的内容管理、审核、配置、统计、回收站和操作日志查看。
- `apps/api`：负责鉴权、业务规则、数据访问、文件上传、审核判断、统计入库和 Swagger 文档。

通信方式：

- 前台和后台均通过 `/api` 前缀访问后端 REST API。
- 管理接口使用 JWT + HttpOnly Cookie 鉴权。
- 访客交互接口通过浏览器生成的 visitorId 辅助识别点赞、留言来源和黑名单匹配。

## 3. 通用设计约定

### 3.1 状态模型

内容类模块统一包含两个状态维度：

- 发布状态：`DRAFT`、`PUBLISHED`。
- 可见范围：`PUBLIC`、`PRIVATE`。

普通访客只能读取 `PUBLISHED + PUBLIC` 内容。管理员后台可读取全部内容。管理员前台预览模式可读取管理员可见内容，并且搜索遵守同样规则。

### 3.2 删除模型

第一版删除默认进入回收站，不直接物理删除。被回收内容需要保留：

- 原业务类型。
- 原业务 ID。
- 标题或摘要。
- 删除时间。
- 删除操作者。
- 恢复所需状态。

回收站支持恢复和彻底删除。彻底删除需要二次确认。自动清理只预留，不启用。

### 3.3 富文本

后台统一使用 WangEditor 维护富文本内容。后端存储富文本 HTML 或结构化结果时，需要保留清洗入口，避免前台直接渲染未经处理的危险内容。第一版可以在保存或输出阶段进行基础 XSS 清理。

### 3.4 上传

第一版使用服务器本地存储：

```text
uploads/
uploads/photos/original/{yyyy}/{mm}/
uploads/photos/large/{yyyy}/{mm}/
uploads/photos/thumb/{yyyy}/{mm}/
uploads/music/
uploads/site/avatar/
uploads/site/mascot/
uploads/site/announcement/
```

上传模块只暴露文件元数据给业务模块，业务模块不直接关心本地路径拼接细节。图片上传后由上传服务负责原图保存、压缩大图、缩略图生成。

## 4. 前台应用设计

### 4.1 前台基础框架模块

职责：

- 路由、页面切换动画、全局布局、导航、多语言、主题模式和加载状态。
- 桌面端与移动端适配。
- 前台固定 UI 支持中文、英文、日文。

关键设计：

- 主题状态存储在 localStorage，默认使用粉色主题。
- 夜间模式使用低饱和粉紫、灰紫、深樱色等柔和暗色，不使用纯黑。
- 页面切换使用轻量淡入和轻微位移。
- 多语言仅覆盖固定 UI 文案，不覆盖内容数据。

可独立测试点：

- 语言切换后刷新仍保持选择。
- 主题切换后刷新仍保持选择。
- 普通访客无法通过前台接口看到私密或草稿内容。

### 4.2 首页模块

职责：

- 展示网站名、公开昵称、网站介绍、看板娘占位图、页面说明、公告、最近碎碎念、最近照片、留言入口和全站点赞入口。

接口依赖：

- 系统设置接口。
- 公告接口。
- 碎碎念公开列表接口。
- 照片公开列表接口。
- 点赞接口。
- 看板娘配置接口。

关键设计：

- 公告只在首页展示。
- 公告关闭状态存储在 localStorage。
- 首页顶部提供公告图标，点击后重新显示公告。

可独立测试点：

- 公告关闭后再次进入首页不自动弹出。
- 点击公告图标可再次显示公告。
- 最近内容只展示已发布且公开的数据。

### 4.3 碎碎念模块

职责：

- 前台展示短句碎碎念列表。
- 支持按标签筛选。
- 支持无限滚动。
- 支持配图展示和点赞。

接口依赖：

- 碎碎念公开列表接口。
- 标签公开列表接口。
- 点赞接口。

关键设计：

- 心情字段仅在数据结构中预留，不在前后台界面开放。
- 列表接口采用游标或页码分页均可，但前台表现为无限滚动。

可独立测试点：

- 标签筛选只影响碎碎念列表，不影响其他模块。
- 无限滚动重复加载时不出现重复项。
- 点赞和取消点赞状态正确回显。

### 4.4 随笔模块

职责：

- 前台展示随笔列表和详情页。
- 支持分类筛选、标签展示、置顶、无限滚动和点赞。
- 第一版不展示前台评论。

接口依赖：

- 随笔公开列表接口。
- 随笔公开详情接口。
- 随笔分类接口。
- 标签接口。
- 点赞接口。

关键设计：

- 详情页仅允许普通访客访问已发布且公开随笔。
- 评论接口由后端和后台实现，但前台不挂载评论展示组件。

可独立测试点：

- 草稿随笔无法通过详情 URL 被普通访客访问。
- 分类筛选和标签展示正确。
- 前台不出现评论入口或评论列表。

### 4.5 照片墙模块

职责：

- 展示照片缩略图。
- 支持按相册筛选。
- 支持大图预览。
- 支持手动排序结果。
- 支持照片点赞。

接口依赖：

- 照片公开列表接口。
- 相册公开列表接口。
- 点赞接口。

关键设计：

- 列表优先加载缩略图。
- 预览时先使用缩略图过渡放大，再加载压缩大图或高清图。
- 照片标签仅预留，不开放使用。

可独立测试点：

- 切换相册后列表排序仍正确。
- 大图预览关闭后回到原列表位置。
- 私密照片不出现在公开列表和搜索结果中。

### 4.6 留言板模块

职责：

- 提供访客留言表单和公开留言列表。
- 留言字段为昵称、邮箱、内容。
- 使用默认头像。
- 列表使用无限滚动。

接口依赖：

- 留言提交接口。
- 留言公开列表接口。

关键设计：

- 留言不允许匿名，因此昵称、邮箱、内容均必填。
- 前端生成或读取 visitorId 并随提交传给后端。
- 命中违禁词或黑名单的留言进入待审核；未命中时自动公开。
- 第一版不实现留言回复流程。

可独立测试点：

- 空昵称、空邮箱、空内容不能提交。
- 命中违禁词后前台不立即公开显示。
- 未命中违禁词时提交后可在公开列表中出现。

### 4.7 搜索模块

职责：

- 提供弹窗快速搜索面板和独立搜索结果页。
- 搜索范围包括碎碎念、自定义页面、随笔、照片标题和描述、留言内容。
- 搜索结果按内容类型分区展示。

接口依赖：

- 前台搜索接口。

关键设计：

- 普通访客搜索仅返回已发布且公开内容。
- 管理员预览模式搜索可返回管理员可见内容。
- 弹窗展示少量快速结果，完整结果页展示更多分区结果。

可独立测试点：

- 搜索私密内容时普通访客无结果。
- 弹窗和结果页使用同一搜索规则。
- 不同内容类型分区互不污染。

### 4.8 音乐播放器模块

职责：

- 全站固定角落显示播放器。
- 支持播放列表、切歌、单曲循环、随机播放、歌词展示。
- 默认不自动播放。

接口依赖：

- 公开音乐列表接口。

关键设计：

- 用户上次播放选择、播放模式等状态存储在 localStorage。
- 移动端布局需要避开主内容和底部操作区域。
- 有歌词时显示歌词，无歌词时显示歌曲名和歌手。

可独立测试点：

- 默认不自动播放。
- 切换播放模式后刷新仍保持。
- 无歌词数据时回退展示歌曲信息。

### 4.9 看板娘模块

职责：

- 第一版展示静态占位图。
- 按页面展示台词气泡。
- 点击后按权重随机显示台词。

接口依赖：

- 看板娘公开配置接口。

关键设计：

- 显示范围由后台配置控制。
- Live2D 配置仅预留，不启用。
- 权重随机由前端或后端计算均可，但同一配置接口需要返回权重信息。

可独立测试点：

- 不在显示范围内的页面不显示看板娘。
- 页面切换后展示对应页面说明。
- 随机台词只来自已启用台词池。

### 4.10 关于我与错误页模块

关于我职责：

- 展示个人介绍、兴趣、建站说明、头像和 GitHub 链接。
- 不展示联系方式。

错误页职责：

- 覆盖 404 和 500。
- 提供返回上一页、重新加载入口。
- 不提供返回首页和搜索入口。

待确认：

- Cloudflare 名称、商标和仿官方错误页的使用边界需要在实现前再次确认。

## 5. 后台应用设计

### 5.1 后台基础框架模块

职责：

- 登录页、后台主布局、菜单、路由守卫、请求封装、权限态维护。
- 使用 Element Plus。
- 只适配电脑端，浅色管理界面。

关键设计：

- 后台不使用现成模板，从零搭建布局。
- 后台接口请求依赖 HttpOnly Cookie，不在前端可读存储 JWT。
- 登录态通过管理员信息接口确认。

可独立测试点：

- 未登录访问后台页面会跳转登录页。
- 登录成功后可访问后台。
- Cookie 过期后接口返回未授权并引导重新登录。

### 5.2 登录与账号模块

职责：

- 管理员账号密码登录。
- 登出。
- 修改密码。
- 记住我。

接口依赖：

- 登录接口。
- 登出接口。
- 当前管理员信息接口。
- 修改密码接口。

关键设计：

- 第一版只支持一个管理员账号。
- 默认账号 `admin`，默认初始密码 `admin123`。
- 默认登录有效期 24 小时；勾选记住我后 7 天。
- 生产环境首次使用后需要修改默认密码。

可独立测试点：

- 密码错误不能登录。
- 记住我影响 Cookie 有效期。
- 修改密码后旧密码不可再登录。

### 5.3 仪表盘模块

职责：

- 展示访问量和点赞趋势。
- 提供常用入口。
- 使用 ECharts 做图形化展示。

指标：

- 总访问量。
- 今日访问量。
- 最近 7 天访问趋势。
- 最近 30 天访问趋势。
- 点赞总数。
- 最近 7 天点赞趋势。

可独立测试点：

- 图表数据和接口返回一致。
- 不展示 PRD 明确排除的内容数量和最新列表。

### 5.4 内容管理模块

覆盖：

- 导航。
- 自定义页面。
- 碎碎念。
- 随笔。
- 随笔分类。
- 标签。
- 照片。
- 相册。

通用能力：

- 新增、编辑、删除。
- 分页列表。
- 草稿和已发布。
- 公开和仅自己可见。
- 置顶。
- 回收站。
- 操作日志。

模块边界：

- 标签作为独立模块，由内容模块通过关联表使用。
- 相册分类独立于标签。
- 随笔分类独立于统一标签。
- 上传由上传模块处理，内容模块只保存文件引用。

可独立测试点：

- 各内容模块 CRUD 不依赖其他内容模块。
- 删除进入回收站，恢复后原内容可继续编辑。
- 标签适用范围限制在允许的内容类型内。

### 5.5 留言与评论审核模块

职责：

- 留言审核。
- 评论 CRUD。
- 评论后台回复。
- 违禁词命中展示。
- 黑名单命中处理。

关键设计：

- 留言和评论复用同一套审核规则。
- 命中违禁词或黑名单时进入 `PENDING`。
- 未命中违禁词时留言自动公开。
- 拒绝内容保留记录。
- 评论支持层级回复，但前台第一版不展示评论。

可独立测试点：

- 违禁词命中列表正确记录。
- 黑名单命中不会直接拒绝或丢弃。
- 评论层级关系保存正确。

### 5.6 音乐管理模块

职责：

- 维护音乐列表。
- 上传本地音乐文件。
- 填写外部音乐链接。
- 维护歌曲名、歌手、播放列表、歌词文本和 `.lrc` 文件。

关键设计：

- 本地文件和外部链接二选一或至少一种有效。
- 歌词文本和歌词文件都通过音乐记录关联。

可独立测试点：

- 上传格式和大小限制生效。
- 无音频来源不能保存。
- 歌词文件格式限制生效。

### 5.7 看板娘管理模块

职责：

- 管理看板娘图片。
- 配置显示范围。
- 配置页面台词。
- 配置随机台词池和权重。
- 预留 Live2D 配置。

可独立测试点：

- 禁用页面不返回前台展示配置。
- 权重字段保存和读取一致。
- Live2D 预留字段不影响静态图展示。

### 5.8 系统设置与公告模块

职责：

- 维护网站名、公开昵称、首页介绍、GitHub 链接、默认看板娘配置和公告。
- 公告使用富文本，只在首页显示。

关键设计：

- 系统设置适合使用 key-value 或分组配置表。
- 主题色、favicon、备份能力只预留，不开放后台界面。

可独立测试点：

- 修改设置后前台首页读取到最新值。
- 公告关闭状态由前台保存，后台修改公告内容不直接依赖前台状态。

### 5.9 回收站模块

职责：

- 汇总可回收业务类型。
- 支持恢复和彻底删除。
- 支持按类型筛选。

覆盖：

- 碎碎念、随笔、照片、自定义页面、留言、评论、音乐、导航、标签。

可独立测试点：

- 不同类型内容恢复后回到原管理模块。
- 彻底删除需要二次确认。
- 操作日志记录恢复和彻底删除动作。

### 5.10 操作日志模块

职责：

- 记录管理员登录、新增、编辑、删除、审核、修改设置、修改密码等操作。
- 记录管理员操作 IP 完整值。
- 后台不可手动删除日志。
- 按保留时间自动清理，默认 90 天。

可独立测试点：

- 关键管理操作均写入日志。
- 后台无手动删除入口。
- 保留时间配置可读取。

## 6. 后端模块设计

### 6.1 NestJS 模块划分

后端建议按业务能力拆分模块：

```text
AuthModule
AdminModule
NavigationModule
PageModule
ThoughtModule
EssayModule
EssayCategoryModule
PhotoModule
AlbumModule
MessageModule
CommentModule
LikeModule
TagModule
SearchModule
UploadModule
MusicModule
MascotModule
SettingModule
AnnouncementModule
StatisticModule
AuditModule
ForbiddenWordModule
BlacklistModule
RecycleBinModule
OperationLogModule
PrismaModule
```

模块原则：

- Controller 只处理请求、参数校验和响应。
- Service 处理业务规则。
- Repository 或 Prisma 查询逻辑集中在 Service 内部或独立数据访问层。
- 跨模块调用通过导出的 Service 完成，不直接跨模块访问对方内部实现。
- 审核、回收站、操作日志属于通用能力，可被业务模块调用。

### 6.2 鉴权模块

职责：

- 登录、登出、JWT 签发、Cookie 写入、管理员身份校验、修改密码。

关键设计：

- JWT 存入 HttpOnly Cookie。
- 管理接口使用 Guard 校验 Cookie 中 JWT。
- 密码需要哈希存储。
- 修改密码后可使旧登录态失效，具体实现可通过密码版本号或 token 签发时间校验。

测试重点：

- 登录成功写入 Cookie。
- 管理接口无 Cookie 时拒绝访问。
- 修改密码后旧密码失效。

### 6.3 内容模块

覆盖：

- 导航、自定义页面、碎碎念、随笔、分类、照片、相册、标签。

关键设计：

- 内容查询统一封装可见性过滤条件。
- 后台分页使用 page/pageSize。
- 前台无限滚动接口返回 items、nextCursor 或分页信息。
- 删除统一调用回收站服务。

测试重点：

- 普通访客查询只返回公开已发布内容。
- 管理员查询返回全部内容。
- 删除后业务列表不再显示，回收站可见。

### 6.4 审核模块

职责：

- 为留言和评论提供统一审核规则。
- 处理违禁词检测。
- 处理黑名单匹配。
- 记录命中的违禁词。

关键设计：

- 第一版违禁词使用直接命中规则。
- 正则能力只预留字段，不启用。
- 命中违禁词或黑名单均进入待审核。
- 未命中时留言自动公开。

测试重点：

- 直接命中违禁词进入待审核。
- 命中黑名单进入待审核。
- 未命中自动通过。

### 6.5 点赞模块

职责：

- 支持全站、碎碎念、随笔、照片点赞与取消点赞。
- 按对象类型统计点赞数。
- 提供点赞趋势数据。

关键设计：

- 点赞唯一性由 visitorId、targetType、targetId 共同决定。
- 全站点赞可使用固定 targetType 和空 targetId 或固定 targetId。
- 再次点赞同一对象时取消点赞。

测试重点：

- 同 visitorId 同对象不能重复累计。
- 再次点击后取消点赞。
- 不同对象统计互不影响。

### 6.6 搜索模块

职责：

- 聚合搜索碎碎念、自定义页面、随笔、照片、留言。
- 前台按权限过滤。
- 后台各管理模块内提供查询能力。

关键设计：

- 第一版可基于 MySQL LIKE 或全文索引能力实现。
- 搜索服务负责聚合结果，业务模块负责提供本模块搜索条件和权限过滤。
- 搜索结果按内容类型分区返回。

测试重点：

- 私密或草稿内容不会出现在普通访客搜索结果中。
- 搜索结果分区正确。

### 6.7 统计模块

职责：

- 记录访问统计。
- 统计页面浏览量、今日访问量、7 天和 30 天趋势。
- 提供仪表盘数据。

关键设计：

- 不记录 referrer。
- 访客 IP 需要脱敏后保存。
- 浏览器和设备只保存大类或必要字段。
- 覆盖内置页面和自定义页面。

测试重点：

- 访问记录入库。
- IP 不保存完整原始值。
- 仪表盘聚合结果正确。

### 6.8 上传模块

职责：

- 文件格式校验。
- 文件大小校验。
- 本地存储路径生成。
- 图片多规格生成。
- 返回文件元数据。

关键设计：

- 图片单文件限制 10MB。
- 音乐单文件限制 20MB。
- 看板娘图片不限制大小，但仍需格式校验。
- 文件 URL 和物理路径分开保存，便于未来迁移对象存储。

测试重点：

- 非允许格式被拒绝。
- 超出大小限制被拒绝。
- 照片上传生成原图、大图、缩略图记录。

## 7. 数据库概要设计

数据库使用 MySQL 8.0.30，ORM 使用 Prisma，表结构通过 Prisma migration 管理。详细字段、索引、枚举和软删除规则后续可单独产出数据库设计文档。

### 7.1 核心实体

账户与权限：

- `admins`：单管理员账号、密码哈希、密码版本、创建时间、更新时间。

内容：

- `navigations`：导航名称、类型、站内路径或外链、父级、排序、启用状态、软删除。
- `pages`：自定义页面标题、slug、富文本内容、发布状态、可见范围、SEO 预留字段、软删除。
- `thoughts`：碎碎念内容、配图、标签关联、发布状态、可见范围、置顶、心情预留字段、软删除。
- `essays`：随笔标题、内容、分类、标签关联、发布状态、可见范围、置顶、软删除。
- `essay_categories`：随笔分类名称、排序、启用状态。
- `photos`：照片标题、描述、原图、大图、缩略图、相册、排序、可见范围、软删除。
- `albums`：相册名称、描述、排序、启用状态。

互动与审核：

- `messages`：昵称、邮箱、内容、头像、visitorId、IP 信息、审核状态、命中词记录、软删除。
- `comments`：随笔 ID、父评论 ID、昵称、邮箱、内容、visitorId、审核状态、层级关系、软删除。
- `likes`：visitorId、对象类型、对象 ID、创建时间。
- `forbidden_words`：词条、规则类型预留、启用状态。
- `blacklist_items`：类型、值、启用状态、备注。

配置与展示：

- `tags`：标签名、适用范围、启用状态。
- `tag_relations`：标签与内容对象关联。
- `musics`：歌曲名、歌手、本地文件、外部链接、歌词文本、歌词文件、排序、启用状态、软删除。
- `mascots`：图片、显示范围、Live2D 预留配置、启用状态。
- `mascot_lines`：页面标识、台词内容、权重、启用状态。
- `settings`：配置 key、配置 value、配置分组。
- `announcements`：公告内容、启用状态、更新时间。

治理与统计：

- `visit_logs`：页面类型、页面 ID 或路径、脱敏 IP、浏览器大类、设备大类、访问日期、创建时间。
- `operation_logs`：管理员 ID、操作类型、对象类型、对象 ID、完整 IP、详情、创建时间。
- `recycle_bin_items`：业务类型、业务 ID、标题、删除前摘要、删除人、删除时间。

### 7.2 索引方向

建议索引：

- 内容列表：发布状态、可见范围、置顶、排序、创建时间。
- 详情访问：slug、id。
- 标签关联：targetType、targetId、tagId。
- 点赞唯一：visitorId、targetType、targetId。
- 审核列表：审核状态、创建时间。
- 搜索字段：标题、内容摘要、描述。具体全文索引方案在详细数据库设计阶段确定。
- 访问统计：访问日期、页面类型、页面 ID。
- 操作日志：管理员 ID、操作类型、创建时间。
