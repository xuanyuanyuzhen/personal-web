# 鉴权与后台基础框架

- [x] 实现密码哈希存储和校验。
- [x] 实现 `POST /api/auth/login`。

- [x] 实现 `GET /api/auth/me`。
- [x] 实现 `POST /api/auth/change-password`。
- [x] 修改密码后使旧密码不可再登录。
- [x] 创建后台登录页。
- [x] 登录页显示本地开发默认账号提示。
- [x] 创建后台主布局。
- [x] 创建后台菜单和路由配置。
- [x] 实现后台路由守卫。
- [x] 实现后台请求封装，自动携带 Cookie。
- [x] 未登录访问后台页面时跳转登录页。
- [x] Cookie 过期或接口 401 时引导重新登录。
- [x] 创建修改密码页面或弹窗。
- [x] 记录登录和修改密码操作日志。

验收标准：

- [x] 正确账号可登录后台。
- [x] 错误密码不能登录。
- [x] 退出登录后不能访问后台受保护页面。
- [x] 修改密码后旧密码失效。
