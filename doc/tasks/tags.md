# 标签管理

目标：实现统一标签管理，并供碎碎念、随笔、照片预留或使用。
- [x] 实现标签管理 API 列表分页。
- [x] 实现标签新增接口。
- [x] 实现标签编辑接口。
- [x] 实现标签删除进入回收站。
- [x] 支持标签启用状态。
- [x] 支持标签适用范围：碎碎念、随笔、照片。
- [x] 实现标签公开列表接口。
- [x] 后台实现标签列表页。
- [x] 后台实现标签新增和编辑表单。
- [x] 后台表单支持适用范围选择。

- [x] 标签新增、编辑、删除写入操作日志。

- [x] 碎碎念只能选择适用于碎碎念的标签。
