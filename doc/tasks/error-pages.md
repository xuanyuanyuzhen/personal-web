# 错误页

目标：实现前台 404 与 500 错误页，并保留参考项目许可与商标边界确认点。

- [x] 实现前台 404 路由。
- [x] 实现前台 500 页面。
- [x] 错误页视觉采用 Cloudflare 风格方向。
- [x] 错误页不带语尔个人站粉色视觉。
- [x] 错误页提供返回上一页入口。
- [x] 错误页提供重新加载入口。
- [x] 错误页不提供返回首页入口。
- [x] 错误页不提供搜索入口。
- [x] 固定 UI 文案纳入前台多语言。
- [x] 实现前确认 `donlon/cloudflare-error-page` MIT 许可保留方式。
- [x] 实现前确认 Cloudflare 名称、商标和仿官方错误页使用边界。
- [x] 如使用参考项目代码或资源，在项目中保留 MIT 许可声明。
- [x] 为未知路由跳转 404 编写前端测试。

说明：当前实现采用通用网络诊断页布局，没有使用 `donlon/cloudflare-error-page` 代码、资源、Cloudflare 名称或商标，因此无需额外保留第三方 MIT 许可文件。

验收标准：

- [x] 未知路由显示 404。
- [x] 500 页面可被错误状态调用。
- [x] 页面只提供返回上一页和重新加载两个入口。
