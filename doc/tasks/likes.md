# 点赞

目标：实现全站、碎碎念、随笔、照片的点赞与取消点赞。

- [x] 定义点赞对象类型：site、thought、essay、photo。
- [x] 实现点赞切换接口 `POST /api/likes/toggle`。
- [x] 使用 visitorId、targetType、targetId 判断唯一性。
- [x] 同一对象再次点赞时取消点赞。
- [x] 返回当前对象点赞数。
- [x] 返回当前 visitorId 是否已点赞。
- [x] 实现公开对象点赞状态查询能力。
- [x] 实现按对象类型统计点赞数。
- [x] 实现最近 7 天点赞趋势聚合。
- [x] 前台实现通用爱心点赞按钮。
- [x] 点赞按钮支持已点赞和未点赞状态。
- [x] 点赞和取消点赞有动画反馈。
- [x] 首页接入全站点赞。
- [x] 碎碎念接入点赞。
- [x] 随笔列表或详情接入点赞。
- [x] 照片预览或列表接入点赞。
- [x] 后台在相关模块可查看点赞数。
- [x] 为点赞切换和唯一性编写后端测试。

验收标准：

- [x] 同一 visitorId 对同一对象不会重复累计。
- [x] 再次点击后点赞数减少。
- [x] 不同对象类型统计互不影响。
