# 语尔个人网站需求提案 v0.1

## 1. 项目定位

项目名称：语尔

公开昵称：轩辕宇振

项目类型：个人网站 + 配套后台管理系统

整体定位：

语尔是一个偏粉色、安静记录风格、带二次元元素的个人记录站。前台用于公开展示内容，后台用于站长登录后维护内容。

网站不以技术介绍为主，而是用于记录个人经验、心路历程、碎碎念、照片墙和一些公开给他人浏览的内容。

## 2. 已确认的整体风格

- 整体以粉色系为主。
- 氛围偏安静记录。
- 首页第一眼希望像日记本。
- 首页需要有二次元角色介绍和网站介绍。
- 希望有看板娘。
- 看板娘第一版先使用占位图，后续再替换为现成图片。
- 网站可以公开给别人访问。
- 照片墙内容由站长自己上传，不以真实生活照片为主。
- 前台所有内容列表都需要尽量多样化排版。
- 多样化排版需要保持统一视觉风格，但卡片布局、尺寸、节奏可以有变化，避免模板化重复。
- 前台需要夜间模式。
- 夜间模式切换需要过渡动画。
- 夜间模式不能直接使用纯黑替代。
- 夜间模式需要使用柔和的暗色系，例如低饱和粉紫、灰紫、深樱色等。
- 夜间模式需要记住用户选择。
- 用户切换主题后，下次访问保持上次选择。
- 前台需要页面切换动画。
- 页面切换动画应轻柔克制，例如淡入、轻微位移，不影响阅读。
- 前台需要加载动画。
- 加载动画需要符合粉色日记本和二次元氛围。

## 3. 用户角色

### 3.1 访客

- 不需要登录即可访问前台个人网站。
- 只能看到公开内容。
- 可以访问留言板。
- 可以进行点赞。

### 3.2 管理员

- 目前只需要一个管理员账号。
- 管理员需要登录后台。
- 管理员可以维护网站内容、导航、照片、留言审核等数据。

前台网站面向公开访问，不需要登录。

- 前台需要适配移动端。
- 前台需要同时考虑桌面端和手机端访问体验。

- 第一版不接入 Gravatar。
- 留言字段包括昵称、邮箱、内容。
- 留言不需要网站链接字段。

- 后台留言管理列表使用分页。

点赞对象已确认包括：

## 6. 后台管理系统需求

后台需要登录后访问，仅管理员使用。

已确认：

- 后台管理系统第一版只适配电脑端。
- 后台暂不要求移动端管理体验。
- 后台第一版不需要夜间模式。
- 后台保持浅色管理界面。

### 6.1 登录

已确认：

- 后台需要登录。
- 目前只需要一个管理员账号。
- 后台登录第一版只使用账号密码。
- 第一版暂不接入图形验证码或邮箱验证码。
- 后台登录页面需要显示默认密码提示。
- 后台需要支持管理员修改密码。
- 默认密码提示仅用于初始化或本地开发阶段，生产环境需要避免暴露真实密码。
- 数据库初始化需要创建默认管理员账号。
- 默认管理员账号为 `admin`。
- 默认管理员初始密码为 `admin123`。
- 生产环境首次使用后需要修改默认密码。
- 后台登录有效期为 24 小时。
- 后台登录需要提供“记住我”选项。
- 未勾选“记住我”时，登录有效期为 24 小时。
- 勾选“记住我”时，登录有效期为 7 天。

## 8. 技术栈

已确认：

- 项目采用 monorepo 结构。
- monorepo 第一版采用普通 pnpm workspace。
- 第一版不引入 Turborepo 或 Nx。
- 前台网站使用 Vue 3 + TypeScript + Vite。

- 后台管理接口通过 JWT 校验管理员身份。
- 富文本编辑器使用 WangEditor。
- WangEditor 用于后台统一编辑自定义页面、文章或记录、关于我等富文本内容。
- 图片上传第一版采用服务器本地存储。
- 后续图片存储方案待定，可能不会继续放在服务器本地。
